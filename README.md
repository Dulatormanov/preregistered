# preregistered

An agent guesses a label for every new public issue in [supabase/supabase](https://github.com/supabase/supabase), every 15 minutes, and locks each guess before any person labels the issue: a hash of the new guesses goes on the [Notary log](https://github.com/Dulatormanov/preregistered/issues/1), and GitHub stamps the time. Later, the labels that maintainers add show how often it agreed. The rules were written down, and anchored, before any result existed ([`PREREGISTRATION.md`](PREREGISTRATION.md)).

It only reads Supabase's public data. It never writes to Supabase's repositories, and it stores numbers, labels and hashes, never issue text.

## The parts

1. **The clock:** a 15-minute tick reads new issues, queues them in Postgres (pgmq), and a worker guesses each one in its own transaction ([`runner/`](runner/), ADR-003).
2. **The score:** later human labels decide agreement, on a sealed set of 151 older issues (scored once) and on live issues ([`rules/ground_truth.toml`](rules/ground_truth.toml), ADR-006).
3. **The eval gate:** a required check with three tiers, safety, regression and capability, and a weekly bad change it must block ([`gate/decide.py`](gate/decide.py), ADR-005).
4. **The model watcher:** tests each new Anthropic model and opens an ADOPT, HOLD, INCONCLUSIVE or SKIPPED pull request ([`adopt/`](adopt/)).
5. **The one governed write:** one label in a sandbox repo, only after the owner approves the exact bytes ([`gateway/gateway.py`](gateway/gateway.py), ADR-004).
6. **The alarms:** they notice a run that never happened, or one that "succeeded" but did nothing ([`ops/watchdog.py`](ops/watchdog.py), a replay of a real outage).
7. **The contact budget:** the database limits how often the system may message a person (ADR-008).
8. **The weekly report agent:** a short Monday report, checked first for invented progress, a private item, an accusation and misplaced credit ([`agents/report_checks.py`](agents/report_checks.py)).

Every job logs in to Postgres as its own role and writes only through functions ([`db/`](db/), [`credentials.toml`](credentials.toml)); every job is in the registry ([`agents/registry.toml`](agents/registry.toml)).

## Check it yourself

From a clean clone, with a read-only GitHub token: `make verify` recomputes every anchor from the public `data` branch, the Notary log and git, and `make tables-public` scores the revealed guesses from GitHub's public label events. Guesses go public 14 days after they are saved.

The decisions, day by day, are in [`DECISIONS.md`](DECISIONS.md), and what was harder than it should be in [`FRICTION_LOG.md`](FRICTION_LOG.md).
